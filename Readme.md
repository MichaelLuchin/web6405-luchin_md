## Лабораторная работа №3. Основы JavaScript

Папка: [`lab3`](./lab3), ветка: `lab3`.

**Цель:** изучить основы JavaScript.

**Что сделано.** В `lab3/src/core.js` реализован набор функций по каркасу
[teach-kirshdv/js-tasks](https://github.com/teach-kirshdv/js-tasks):

| Функция | Что делает | Приём |
| --- | --- | --- |
| `isInteger(n)` | проверяет, что число целое | побитовое `\| 0` |
| `even()` | чётные числа от 2 до 20 | цикл с шагом 2 |
| `sumTo(n)` | сумма чисел от 1 до `n` | цикл |
| `recSumTo(n)` | то же самое | рекурсия |
| `factorial(n)` | факториал | цикл |
| `isBinary(n)` | является ли `n` степенью двойки | деление на 2 |
| `fibonacci(n)` | `n`-е число Фибоначчи | цикл с парой значений |
| `getOperationFn(initialValue, operatorFn)` | функция, накапливающая результат операции | замыкание |
| `sequence(start, step)` | генератор арифметической прогрессии | замыкание, параметры по умолчанию |
| `deepEqual(a, b)` | глубокое сравнение значений | рекурсия по ключам |

**Запуск тестов:**

```bash
cd lab3
npm install
npm test
```

Форматирование проверяется командой `npm run prettier:check`.
